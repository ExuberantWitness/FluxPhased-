# Figure Data Sources — FluxPhased TAES manuscript

All figures are generated by the scripts in this directory with the shared
style in `paper_plot_style.py`. PDF output is vector; no plotted value is
manually altered after generation.

**Single-source rule (2026-08-29):** all headline numbers, including those
plotted by Figs. 3, 4, and 6, are computed once in `results_table.py`
(written snapshot: `RESULTS_TABLE.json`). Figure scripts import that module;
they must not re-implement aggregation or unit conversion locally. This rule
was introduced after Figure 4 displayed the S6 neutralization as "0.6%"
(the fraction 0.637 formatted as a percent) while the text correctly said
63.7%. `_check_paper_integrity.py` re-derives every number quoted in the
LaTeX sources from this module and fails on any mismatch.
