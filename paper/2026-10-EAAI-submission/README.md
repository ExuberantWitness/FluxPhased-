# FluxPhased Paper Package (2026-10-15)

Materials for the manuscript *"An Auditable Learning-Curve-Driven Automatic
Policy Adjustment Framework for Engineering Reinforcement Learning Control
Systems"* (EAAI submission, special issue VSI: EAAI_Intelligent Systems).

Contents of `FluxPhased-paper-package-20261015.zip`:

- `paper/` — submission-ready sources and PDFs
  - `manuscript_no_authors.tex/.pdf` — blinded manuscript (29 pp)
  - `titlepage_with_authors.tex/.pdf` — title page (authors, CRediT, funding, declarations)
  - `english_v2.tex/.pdf` — full English version
  - `chinese_v2.tex/.pdf` — Chinese counterpart for internal review
  - `figures/` — all figure PDFs (NPG palette; FluxPhased architecture, TD-MPC
    Code-as-Policy bar chart and learning curves, etc.)
- `figure-scripts/` — generators for every figure (rerun to reproduce)
- `data/AuditTune-campaign-evidence.zip` — 9 MB evidence package
  (experiment ledger, 192 agent-written planner sources, reproduction scripts);
  also deposited on Mendeley Data, DOI 10.17632/jhgknm378r.1
- `zcode-paper-writing-guide.md` — the group's working protocol for
  paper writing with coding agents

Dataset DOI: https://doi.org/10.17632/jhgknm378r.1
