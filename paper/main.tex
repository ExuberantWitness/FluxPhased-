\begin{abstract}
% ~200 words. Skeleton of the claim chain:
% (1) We introduce a GPU-accelerated, physics-grounded benchmark for
%     task-level EW co-evolution: multifunction radars with mission deadlines
%     vs cooperative jammers with shared energy budgets, IQ-level link
%     budgets (array-factor gains, incoherent power summation), and a
%     pre-training contestability oracle that PREDICTS game balance before
%     any training.
% (2) In 1-jammer-vs-2-radar self-play (S6, 3 seeds), defense dominates:
%     learned radars neutralize 63.7%+-0.7% of the jammer's marginal
%     disruptive power; this ratio is regime-invariant (snr 12 vs 22 dB).
% (3) Doubling the attacker (2v2, S7, 3 seeds x 3000-iter convergence
%     control) collapses neutralization to 23.0%+-1.1% while the game itself
%     stays a stable, replicable equilibrium (h2h 0.337+-0.014, 3.8x S6).
% (4) A co-located-geometry ablation decomposes the mechanism: attacker
%     count is primary (63.7%->28.4%), cross-fire geometry secondary
%     (28.4%->24.2%).
% (5) [R5, running] Opponent-class mixing recovers singleton robustness
%     at cost X in pairwise defense — OR — mixing alone is insufficient.
\end{abstract}
