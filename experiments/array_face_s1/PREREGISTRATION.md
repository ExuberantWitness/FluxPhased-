# Array-Face S1 Preregistration

**Branch**: `g3-bsta/array-face-s1` off `8f7e72d` (lite R2 exploratory extension)
**Date**: 2026-07-30
**Phase**: S1 of 4-phase incremental array-face roadmap (see `docs/array_face/INCREMENTAL_DESIGN.md`)

## 1. Goal

Phase 1 of incremental array-face research: introduce a real radar array factor
to the lite env, holding the jammer as a single isotropic antenna and the
action space unchanged (`Categorical(3)`).

**Research question**: Does adding a per-step radar array factor to the
JNR link budget change what PPO learns, compared to the lite scalar budget?

## 2. What changes vs lite

| Aspect | lite (g3_bsta_lite) | S1 (array_face_s1) |
|---|---|---|
| Jammer | 1 isotropic antenna, P_jam_W=50 W | unchanged |
| Radar | Scalar rx_gain_db per svc | 5-cell 1D ULA, λ/2 spacing, beam_az scans |
| JNR formula | scalar link budget | +AF_rx_db(beam_az) term |
| Action space | Categorical(3) | unchanged |
| Observation | 11 dims | 16 dims (lite 11 + 5-dim beam_az one-hot) |
| Privileged | 4 dims | 9 dims (lite 4 + 5-dim beam_az one-hot) |
| Profile | pomdp_v1 / mdp_sanity_v1 | same (lite profile reused) |

Frozen radar beam schedule: `radar_beam_az_idx = step_idx % 5` over grid {-60°, -30°, 0°, +30°, +60°}.
The jammer directly observes current `radar_beam_az_idx` (MDP; not POMDP for AF).

## 5. Evaluation

- Validation set: `checkpoint_validation` (64 seeds).
- Validation cadence: every 10 iterations.
- Per-validation: 2 action reps per seed (128 episodes).
- Metric: macro_mean_drop = mean over seeds of mean_drop_over_reps.

## 6. Phase entry criteria (to enter S2)

- All 8 S1 physics unit tests PASS
- All 10 S1 env contract tests PASS
- `MANIFEST_AUDIT.overall_verdict = ALL_DISJOINT_AND_LEGACY_CLEAN`
- lite regression 75/75 PASS (zero lite breakage)
- PPO 1000 iter completed without crash
- Learning curve plotted
- User reviews curve and decides whether to enter S2

**No Gate-3 re-judgment**. S1 results are observational, not pass/fail.

## 7. What S1 does NOT do

- No jammer antenna array (S2 introduces jammer 1D ULA + beam_az action)
- No cell binding (S3 introduces per-cell idle/jam)
- No 2D / elevation (S4 introduces 5×5 UPA)
- No POMDP for AF (jammer directly sees beam_az; future phases may obscure)
- No new R2/Gate-3 verdict on any env
