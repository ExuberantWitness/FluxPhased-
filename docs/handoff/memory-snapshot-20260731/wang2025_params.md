## MDP
- 状态 7 维: 每类最紧急任务 T_k = −1(无)/(0,1) 等待(=剩余窗/可推迟总量,越小越急)/1(执行中)
- 动作 8 离散: a₀=空闲, a_k=执行类型 k 最紧急任务
- Reward(式 11): 成功执行 `10·(1−执行后剩余孔径)`;不可行 `−10`;空闲 `−1`;丢弃 `−(2+P_k/P_max)`

## 复现验收数字
- 丢弃率: **DDQN 33.67%** vs MTPEDF(α=0) ≈39.39%、(α=0.5) ≈45.39%
- 利用率 φ=Σ(η·τ_d)/Δt: **87.52%** vs 82.07% / 77.16%
- 收敛 ~1×10⁵ 步,累积回报 ~0.4;鲁棒性扫描 2000→5000 任务/5s

## 论文模糊处(实现需自行决策)
1. 决策粒度 1ms 是推断;2. 每类只暴露/执行最紧急任务(状态压缩设计,MAPPO 化可放开);3. 无硬件约束(波束切换时间),作者结论自认可作增量;4. MTPEDF 基线绝对数是从"降低 5.72%/11.72%"反推,实现后以对相对差为准
