## 固定的 v1 核心

物理合同通过后，实施最小核心：

- action 为 `idle` 或 `(emitter, physically_addressable_service)`；
- fixed calibrated jammer power；
- platform-derived hard peak-power/beam/episode-energy feasible set；
- masked categorical policy；
- learned/scripted/planner 使用同一 action adapter、mask、resource debit 和 physics path；
- detector/track progress 使用 held-out IQ 验证后的唯一冻结 transition；
- actor 只看可截获的 causal observation/history；
- 若单帧 observation 非充分，actor 与 causal planner 共用 recurrent/belief contract；
- 原 legacy floor 只留作 regression/ablation。

若 mission contract 的目的之一是排除 fixed-power always-on，必须验证：

```text
episode_energy_j < fixed_beam_power_w * maximum_active_duration_s
```

不得用 `team_peak_power_w * duration` 代替。

## 严格 PPO 合同

1. `idle` 永远合法。
2. 每个 mask bit 都必须是 actor-visible observation/history 的确定函数。
3. rollout 保存 sampling 时的 mask、requested action、executed action、log-prob 和 recurrent state。
4. PPO update 只复用保存的 mask，不能重新计算。
5. 训练/科学评估中必须：

```text
requested_action == executed_action
```

任何不等立即使 rollout/run 失败。不得静默投影到 idle 后继续 PPO，因为 requested log-prob 与 executed transition 不匹配。
6. exogenous RNG 使用无状态 event key：

```text
(namespace, scenario, episode, time, entity, event_type)
```

action RNG 独立，不能依赖策略触发事件的调用顺序。

## Comparator 和 gate

每个 competent script family 在 baseline-calibration split 选出一个 finalist，全部冻结。最终 learner 必须超过**每一个** frozen finalist：

\[
d_{i,b}=\operatorname{mean}_{s,a,e}(D^L_{i,s,a,e}-D^b_{s,a,e}),
\]

\[
\min_b\left[
\bar d_b-t_{0.95,K-1}s_b/\sqrt K
\right] > 0.05.
\]

这是 all-script intersection-union gate。不得用：

- calibration winner 单独替代全部脚本；
- locked test 上的 per-scenario post-hoc script maximum 当主 comparator；
- `H0: delta=0`；
- evaluation/scenario seeds 冒充 training seeds；
- 小样本 episode bootstrap 冒充独立训练重复。

两短 seed 只做 smoke test。正式样本量需要预注册 `mu_alt > .05`、保守 SD、power `>=.8`、`N_max` 并用 noncentral-t 求解；`K>=8` 只是最低工程下限。
