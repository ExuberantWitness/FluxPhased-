# Experiment Plan：MFR-IQ `G3-BSTA`

## 1. Principle

实验顺序固定为：

```text
provenance
→ current-env comparator tune + pathwise reachability confirmation
→ IQ/detector fit + untouched physics validation
→ shared resource/action/recurrent-state invariants
→ reduced causal decision test
→ baseline tune/freeze
→ planner development/freeze
→ untouched headroom confirmation
→ two-seed learnability pilot
→ PPO train/validation freeze
→ 6–8 seed full-budget variance pilot + power analysis
→ full independent training seeds
→ locked superiority gate
```

任一 STOP gate 失败，不执行后续 GPU 训练。

默认 seed namespace；如项目已有注册表，保持数值不重叠并更新 manifest。任何 split 的实际 ID、生成分布与首次访问时间都写入只增不改的 split manifest：

### RNG contract and complete crossing

Exogenous random numbers must be counter-based/stateless or otherwise addressable by an event key:

```text
K_exo = (split, scenario_seed, episode_id, time_index,
         entity_id, event_type, draw_index)
K_act = (policy_id, train_seed_or_script_id, scenario_seed,
         episode_id, action_rep, time_index)
```

- `K_exo` 在 learned/script/planner 间完全相同，且不得因某策略多调用一次 RNG 而错位；
- `K_act` 与 environment/arrival/geometry/detector/training-minibatch streams 独立；
- 每个独立 training seed 必须完成同一个预注册 `scenario × episode × action_rep` 笛卡尔网格；
- stochastic scripts 也运行自己的完整 action-rep 网格；deterministic script 显式记 `A=1`；
- scenario、episode、detector 与 action replicas 都是 seed 内重复测量，不能增加最终 training-seed 自由度。

禁止用 headroom-confirm 或 locked-test 数据选择 budget、detector fit、script、planner hyperparameter、primary eval mode、training step、checkpoint 或样本量。若任一 confirm/test split 被提前访问，必须记录 `SPLIT_CONTAMINATION` 并使对应确认性 gate 失效。

## 5. E1 — Current-Environment Reachability

### Comparator freeze

- noise/reactive/blink；
- duty `p in {0,.1,...,1.0}`；
- iid Bernoulli；
- untrained actor；
- greedy one-step；
- sampled 与 argmax 明确分开。

只在 `5000–5031` 上按预注册 scenario-macro mean、hyperparameter grid 和 deterministic tie-break 选择 `b^*_{\mathrm{cur}}`，然后冻结 code/config/hash。`5100–5163` 不得参与选择。

### Bound

- short horizon exact enumeration；
- longer reduced horizon DP/B&B；
- 每个 confirm scenario/replicate 生成一个 pathwise upper bound `U_{s,r}`，并保存 exact certificate 或 admissible B&B gap；
- `U_{s,r}` 与 `B^{b^*_{\mathrm{cur}}}_{s,r}` 使用相同 event-key exogenous randomness；
- approximate MCTS/beam/CEM 只是 lower-bound witness，不是 upper bound；
- full environment 如无 admissible pathwise bound，只能给 causal lower-bound witness 和 `INCONCLUSIVE_CURRENT_BOUND`。

### Interpretation

定义配对差：

\[
g_{s,r}=U_{s,r}-B^{b^*_{\mathrm{cur}}}_{s,r}.
\]

先在 replicate 内聚合，再以 confirm scenario 为独立单位。使用预注册的一侧 paired t upper bound：

\[
\operatorname{UCB}_{95}(\mathbb E[g])
=\bar g+t_{.95,S-1}\frac{s_g}{\sqrt S}.
\]

- `UCB95(E[g]) < .05`：`STOP_CURRENT_G2A_INFEASIBLE`；
- 禁止用 `UCB(U)-UCB(B)`；如必须拆开估计，只能用预注册 simultaneous `UCB(U)-LCB(B)`；
- 不能通过有限策略 sweep 得出 universal impossibility；
- 即使 original action space 有余量，也不能跳过 A0–A5。

## 6. A0 — IQ/Detector Calibration

### Pre-registered grid

- receiver-band JNR：覆盖实际工作区间，至少 `[-10,-5,0,5,10,15,20] dB`；
- baseline SNR/SCR 与 target range/RCS：覆盖 operational envelope；
- receiver bandwidth、matched/mismatched filter、waveform/pulse-compression gain；
- thermal noise、clutter distribution/correlation、interference correlation and spectral overlap；
- pulse/look counts：使用代码中实际集合，至少含 low/mid/high 三点；
- configured target models：nonfluctuating 与实际使用的 Swerling case；
- `Pfa`：从现有 radar requirement 读取并冻结；
- geometry/antenna-gain bins、spot/on-target 与 off-target/cross-talk controls。

### Procedure

1. 仅用 `cal-fit-*` 通过真实 IQ injection、receiver filter、integrator 和 detector 运行 Monte Carlo；
2. 每 cell 自适应采样，直到 95% Wilson CI half-width `<=.01` 或达到预注册 cap；
3. 仅用 fit 数据选择 analytic/lookup form、超参和 uncertainty envelope，然后冻结 hash；
4. 在未触碰的 `cal-val-*` 上验证 operational grid、预注册 interpolation points、off-target control 与 no-jam regression；
5. physics fit/validation seeds 与所有 RL seeds 隔离；validation 失败后只能回到新版本 fit，并废弃旧 validation split，不能在原 validation 上继续调；
6. detector lower/central/upper envelope 在 headroom 与 final sensitivity 前冻结。

### Acceptance

- untouched validation operational grid 上 `max |Pd_fast - Pd_IQ| <= .03`；
- `J=0` 下新模式复现 no-jam completion distribution；
- receiver-band J 增大时 `Pd`/information 不得反向改善；
- 不存在人为 clamp/quantization hard plateau；允许 detector 在物理上渐近接近 `Pfa` 或 1；
- dB/linear unit tests 全部通过。

若 task 是动态 tracking，还必须验证完整 `P^- = FPF^T + Q` prediction、missed detection、association、measurement update、slot identity/latency，以及 covariance/information 到 task completion 的冻结映射；单独累加 Fisher information 不能替代 tracker。

## 7. A1 — Physically Bound Resource and Action Contract

### Invariants

\[
0\le P_{j,t}\le P_{j,\max},\qquad
E_{j,t+1}=E_{j,t}-\Delta t P_{j,t}\ge0,\qquad
\#\{\text{active beams of emitter }j\}\le K_j.
\]

- 只有 R0 证明可池化时才增加 team-level power/energy/beam cap；
- action 为 `idle` 或 `(emitter, physically-addressable service)`；只有单一等效 transmitter 获批时才可退化为 idle-or-target；
- 若合同要求排除 fixed-power always-on，验证 `E_{j,0} < P_{\mathrm{fixed},j} T_{\mathrm{active,max}}`；
- `idle` action 永远合法；
- action mask 在 observation/action sampling 前生成；
- rollout 保存当时 mask；
- PPO update 使用保存的 mask，禁止重新计算；
- scripts/planner 也输出 template ID；
- invalid requested action 必须计数并在 debug mode 抛错，不能悄悄给 learner 优惠；
- requested/executed action 同时记录。
- 对所有合法动作，`requested_action == executed_action`；确认性 evaluation 中 mismatch/invalid/fallback count 必须严格为 0；
- target slot 在 episode 内稳定；若 tracker 允许 identity replacement，必须带 generation ID，旧 recurrent state/mask 不得继承；
- recurrent policy 若启用，hidden state、done mask、sequence boundary 与 vector-env slot 必须逐步保存并在 PPO replay 中复用；若未启用，tracker 中明确记 `NOT_APPLICABLE`；
- tracker 的 identity、age、confidence、dropout/reacquisition 只能来自因果 intercept history，不能读取 hidden truth。

### Replay fairness test

对同一 serialized state 和 template ID，分别走 learned/script/planner adapter，逐项比较：

- decoded target；
- power；
- energy debit；
- in-band J；
- target-local JNR/SINR；
- next resource state。

浮点量用固定 tolerance；policy-type 分支命中即 FAIL。另必须通过：

1. valid action 的 requested/executed exact-equality test；
2. stored-mask vs replay-mask/log-prob test，含 only-idle row；
3. slot permutation、slot disappearance/reappearance、generation-ID test；
4. vector-env done/reset 后 recurrent hidden-state isolation test；
5. tracker latency、identity association、dropout/reacquisition 与 no-hidden-state-leak test；
6. emitter/service selectivity、off-target cross-talk 与 fixed-power always-on infeasibility test；
7. 对每个 mask bit 验证 `mask = f(actor-visible observation/history)`。

### Transition, metric and reward freeze

在 planner/headroom 前冻结一种 task transition、一种 `drop_ratio` numerator/denominator/unfinished-task/macro-or-micro aggregation，以及一种 training reward。不能在 `Pd` expected service、Bernoulli detection draw、Fisher accumulation、newly-dropped count 或 terminal ratio之间根据 headroom 临场切换。zero denominator 记 NaN；zero-energy 的 `drop_per_kJ` 记 NA。

## 8. A2 — Nontrivial Causal Decision

构造 reduced deterministic scenario：

- 2–3 targets；
- target urgency/geometry 在 horizon 中交叉；
- `K=1`；
- 至少 3 个可用 energy quanta；
- no hidden-current-action leakage。

必须证明：

1. 存在相同 `(time, remaining_energy)`、不同 causal history 的可达状态，其最优动作集合不同；被选动作相对次优动作的 Q-value gap 必须同时超过预注册 `epsilon_Q`、solver tolerance 和 Monte Carlo uncertainty；
2. causal DP 相对最佳 open-loop schedule：
   \[
   \operatorname{LCB}_{95}(\Delta_{\mathrm{raw-drop}})>.02;
   \]
3. action permutation、target relabel 与 energy conservation tests 一致；
4. 去掉 target features 或打乱 history 时 oracle/policy 价值下降，而非上升。

失败说明问题仍接近 open-loop schedule，不值得 RL。

### Required scripts

- always-off；
- random feasible；
- budgeted barrage；
- round-robin；
- periodic blink duty/phase family；
- EDF/threat-first；
- reactive follower；
- marginal information/drop per joule；
- small assignment/knapsack lookahead。

### Freeze protocol

1. 在 `1000–1031` baseline-tune scenarios 上，以预注册 scenario-macro mean、有限 hyperparameter grid 与 deterministic tie-break 为每个 required family 选择一个 finalist；
2. 冻结 finalist 的 code SHA、config SHA、family、selection objective、tie-break 与 tune rows；
3. 写 `BASELINE_FREEZE.json`，其中 frozen set 记为 \(\mathcal B\)；
4. planner-development、headroom-confirm、PPO-validation 与 locked-test 均不允许再调任何 script；
5. 不以单一 calibration winner 代替“best scripted”。确认性 claim 必须超过所有 \(b\in\mathcal B\)；若只报告单一 winner，只能称 `calibration-selected comparator`；
6. `test-realized max` 与逐场景 `max_b D_{b,s}` 只能作为保守 sensitivity，不能在看过 locked test 后替换主 comparator。

## 10. A4/A5 — Headroom and Robustness

### Planner development and freeze

只在 `2000–2031` 上开发 reduced DP、beam/MCTS horizon、search budget、operating point 与 causal witness。进入 `2100–2163` 前冻结 planner code/config、primary energy setting、candidate ordering、stopping rule 和 action semantics。任何 confirm 后调参都需要新 proposal、新 confirm split 和新 hash。

### Untouched primary headroom

在至少 32 个未触碰的 headroom-confirm scenarios 上，以 event-key common exogenous RNG 比较。对每个 frozen script \(b\in\mathcal B\)：

\[
h_{s,b}=\frac1R\sum_r\left(
D_{\mathrm{causal\ witness},s,r}
-D_{\mathrm{frozen\ script},b,s,r}
\right).
\]

主 gate 使用以 scenario 为独立单位的 paired one-sample t lower bound：

\[
\operatorname{LCB}_{95,b}
=\bar h_b-t_{.95,S-1}\frac{s_{h_b}}{\sqrt S}.
\]

主 setting 的 PASS 是 intersection–union test：

\[
\min_{b\in\mathcal B}\operatorname{LCB}_{95,b}>.075.
\]

所有脚本均须通过；这不是从多个脚本中挑一个显著结果，因此 global conjunction 不另做 multiplicity 修正。逐脚本 simultaneous interval 如用于单独显著性 claim，使用 Holm/Bonferroni 或预注册 max-t。

### Full sensitivity grid

冻结有限 Cartesian grid：

\[
\mathcal C=
\{\text{energy low, primary, high}\}
\times\{\text{detector lower, central, upper}\}
\times\{\text{nominal, arrival shift, geometry shift}\}.
\]

在同一 untouched confirm split 上运行全部 \(c\in\mathcal C\)；不得只做 one-at-a-time 后挑选。若物理单调性有测试/证明，可用预注册 worst-case cell 代替部分组合，并把证明存档。script/planner 在所有 cells 保持冻结。

\[
\operatorname{PASS}_{A5}\iff
\min_{c\in\mathcal C,\ b\in\mathcal B}
\operatorname{LCB}_{95}(h_{c,b})>.05.
\]

这是“所有 cell × script 都成立”的 IUT；global gate 不另调 alpha。任何 cell 失败或缺失均为 `STOP_G3_BSTA_NO_ROBUST_HEADROOM`，不得称为只在甜点配置外推成功。

## 11. L0 — Two-Seed Learnability Pilot

仅在 A4/A5 通过后运行。

### Runs

- train seeds `9000,9001`；
- short fixed training budget；
- 只使用 PPO training distribution 和 PPO validation；不得访问 headroom-confirm 或 locked test；
- frozen-init actor；
- random feasible；
- trained actor primary mode；
- trained actor with candidate features shuffled within episode；
- trained actor with temporal history shuffled；
- optional behavioral cloning from causal planner 只作诊断，不可混入 PPO 主结果，除非预注册为不同算法。

### Go criteria

- 两个 train seeds 均对 init/random 有一致正向差；
- PPO-validation paired differences 不出现预注册的明显负值；
- shuffle control 显著降低 state-dependent allocation signal；
- conditional action distribution 随 causal candidate features 改变，并超出 permutation null；
- constraint violation 为零；
- return 与 raw drop 方向一致；
- 没有 constant-action、energy dump-at-start 或 mask exploitation。

不把两个 seed 的 p-value、bootstrap CI 或方差当最终 claim/power evidence；它只决定是否值得进入 full-budget variance pilot。

## 12. Power Analysis and Full Training

L0 的两个短训练 seed 不得用于估计 full-budget training-seed variance。另运行预注册 \(K_0=6\text{--}8\)（默认 8）个 full-budget、final-config variance-pilot seeds；它们只在 PPO validation 上评估，不访问 locked test，不按 observed mean 改样本量。

预注册：

- superiority null margin \(m=0.05\)；
- design alternative \(\mu_1>m\) 与 \(\delta_*=\mu_1-m\)；例如 \(\mu_1=.075\) 时 \(\delta_*=.025\)，不得把 `margin=.05` 误当 power effect size；
- `alpha=.05` one-sided；
- target power 至少 `.8`；
- 预注册 `N_max` 与未完成 run 的处理；
- 8 只是最低 floor，不是充分性常数；无可辩护方差上界时不得默认启动 8 seeds。

用 variance-pilot 的 centered training-seed differences 估计 \(s_0\)，取预注册 \((1-\gamma)\) variance upper bound，例如 \(\gamma=.10\)：

\[
\sigma_U
=\sqrt{\frac{(K_0-1)s_0^2}{\chi^2_{\gamma,K_0-1}}}.
\]

对每个候选 \(n\ge8\)：

\[
\lambda_n=\frac{\sqrt n\,\delta_*}{\sigma_U},\qquad
\operatorname{Power}(n)
=P\!\left[T_{n-1,\lambda_n}>t_{.95,n-1}\right].
\]

取最小 `N_power` 使 power `>=.8`，并令 `N_train=max(8,N_power)`；若 `N_train>N_max`，停止或修改研究设计，不得降低 margin/variance。variance pilot 若与 confirmation 使用完全相同 full-budget protocol 且采用预注册 blinded variance-only sample-size re-estimation，可合并；否则不得混入最终 \(N\) 个独立 train-seed rows。

所有 train seeds：

- 相同冻结 config；
- 相同 steps/checkpoint rule；
- 不按 test performance early stop；
- checkpoint selection 只使用 PPO validation 的预注册 rule；
- 保存 optimizer/normalizer state 与 hash。

## 13. Locked G3-BSTA

### Cell metric and zero denominator

每个 `(policy, train_seed/script, scenario, episode, action_rep)` 保存 `dropped_count` 与 `eligible_arrivals`。在预注册 cell 内先 pool episode counts：

\[
D_{i,s,a}
=\frac{\sum_e\mathrm{dropped}_{i,s,e,a}}
{\sum_e\mathrm{eligible}_{i,s,e,a}}.
\]

- denominator 为 0 时 `drop_ratio=NaN`，绝不能写成 0；
- 因 eligible arrivals 属于 common exogenous process，同一 paired cell 的 denominator 应跨策略相同；policy-specific zero/nonzero mismatch 是 RNG/metric FAIL；
- 可按预注册规则为所有策略共同追加 episode replicas 至固定 cap；cap 后仍为 0 则 gate 为 `INCONCLUSIVE_ZERO_DENOMINATOR`，不得静默删除；
- summary 必须报告 NaN/zero-denominator 数、追加规则、cap 与所有被排除 cell。

### Complete grid and per-training-seed aggregates

每个独立 train seed `i` 必须完成相同 locked `S × episode × A` 网格。对每个 frozen finalist \(b\in\mathcal B\)，stochastic script 在与 learner 相同 exogenous block 上用独立 action key 评估：

\[
d_{i,b}=\frac1{SA}\sum_{s,a}
\left(D_{i,s,a}^{L}-D_{i,s,a}^{b}\right).
\]

其中 detector/environment event keys 对策略配对，action RNG 与 exogenous RNG 独立；同一个 `i,s,a` block 内所有 valid actions 必须满足 `requested==executed`，任何 mismatch/invalid/fallback count 非零都使 gate 无效。

### Primary conditional test

对每个 \(b\in\mathcal B\)：

\[
\mathrm{SE}_b=\frac{s_{d_b}}{\sqrt N},\qquad
t_b=\frac{\bar d_b-.05}{\mathrm{SE}_b},
\]

\[
p_b=1-F_{t_{N-1}}(t_b),\qquad
\mathrm{LCB}_{95,b}
=\bar d_b-t_{.95,N-1}\mathrm{SE}_b.
\]

这是 one-sample t p-value，不称 `exact p`。主 PASS：

\[
\min_{b\in\mathcal B}\mathrm{LCB}_{95,b}>.05.
\]

这是“超过所有 frozen scripts”的 IUT；不能只选择 locked-test point estimate 最大或最容易通过的 comparator。主检验的独立单位只有 training seed，推断口径是：

> conditional on this preregistered locked scenario suite and evaluation grid.

### Crossed scenario-population sensitivity

若 claim 要推广到 simulator 的 scenario distribution，而非只限 locked suite，必须另对

\[
z_{i,s,b}=\frac1A\sum_a(D^L_{i,s,a}-D^b_{i,s,a})
\]

拟合预注册 crossed model：

\[
z_{i,s,b}=\mu_b+u_i+v_s+w_{i,s},
\]

其中 training seed 与 scenario 是 crossed random effects，action/episode 是 cell 内重复。报告

\[
\widehat{\operatorname{Var}}(\hat\mu_b)
=\hat\sigma_u^2/N+\hat\sigma_v^2/S
+\hat\sigma_w^2/(NS)
\]

及 Satterthwaite/Kenward–Roger 或预注册 two-way cluster sensitivity。若该 crossed gate 不通过，只能保留 locked-suite 条件性 claim。

当 \(N\) 很小时，percentile/BCa bootstrap 不得替代主 training-seed t gate，episode/action rows 也不得作为 iid bootstrap 单位。可在对称性可辩护时对 \(d_{i,b}-.05\) 做全枚举 sign-flip sensitivity；如做 bootstrap，必须以 training seed 为 cluster，scenario-population sensitivity 中独立重采样 train/scenario，并明确标为 secondary。

同时报告：

- one-sided t p-value for the 5pp null；
- training-seed rows；
- scenario/action-seed rows；
- mean、median、CI、probability of improvement；
- sampled primary/argmax secondary，或反之，以冻结 protocol 为准；
- 每个 frozen script 的结果与全 sensitivity-grid rows；
- conditional 与 crossed inference 的不同 estimand/verdict；
- requested/executed mismatch、invalid/fallback、NaN/zero-denominator counts。

## 14. Required Ablations

1. `legacy_sqrt` vs calibrated task progress；
2. hard energy only vs hard energy + target selection；
3. no target features / shuffled target features；
4. marginal-index script vs causal planner；
5. detector lower/central/upper calibration；
6. primary/adjacent budget settings；
7. sampled vs argmax，仅作预注册 secondary；
8. current old on/off environment，作为历史 negative control。

这些 ablation 是预注册 secondary/exploratory evidence，不得用于更换 primary budget、detector envelope、script、eval mode 或 checkpoint。frequency hopping、exposure/thermal、continuous power、多波束不进入 G3-BSTA 首版 ablation。
